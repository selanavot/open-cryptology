## Letter (below the search box)

Hello cryptographers!

This is an unofficial, non-commercial mirror of the Cryptology ePrint Archive. AI agents have
become useful for research, including literature review, but only if they can access prior work.
ePrint's access control currently blocks them from fetching the PDFs. This mirror is meant to
make that kind of work easy again.

**New papers** appear here within minutes of being accepted on ePrint. We don't take
submissions; submit to ePrint as usual.

**PDFs** come from existing public copies, and readers fill in the gaps: if one is missing,
download it from ePrint and upload it anonymously here.

**Licenses.** Every paper keeps its authors' license and links back to the original. Please
respect it: credit the authors, no commercial use for NC papers, unmodified copies only for ND.

**What's next.** The vision is a one-stop place for everything known about each paper, kept up
to date as cryptography moves on: discussion, links between papers and the protocols they build
on, and known attacks on each construction.

Something wrong or missing? [Contact us] or [open an issue]. Want to help? Get in touch!

Thanks for visiting,
Sela
